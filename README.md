# Akhona Help Care - Web Application (WEDE5020 Part 2)

## Overview
Akhona Help Care is a responsive web application designed to simplify patient care management, online consultation bookings, and medical service inquiries. Developed as part of the **WEDE5020 Part 2** coursework, this project demonstrates front-end web development best practices, accessibility standards, semantic HTML5 structure, and modular CSS design.

---

```text

├── index.html              # Landing page with service summary and call-to-action
├── booking.html            # Online appointment booking interface

├── css/

├── images/
```

## Core Features & Functionality

### 1. Home Page (`index.html`)

* Hero banner featuring quick action buttons for patient navigation.
* Overview of clinic services including primary healthcare, consultations, and emergency contacts.
* Fully responsive navigation bar for seamless browsing across mobile and desktop.

### 2. Appointment Booking (`booking.html`)

* Interactive appointment booking form capturing patient details, preferred dates, times, and medical department.
* HTML5 form validation ensuring required fields (email, phone, date) are filled correctly prior to submission.

### 3. Client Enquiry Form (`enquiry.html`)

* Structured contact form for general questions, feedback, and support inquiries.
* Accessible input labels and clean field layouts designed for optimal user experience.

### 4. Custom Styling & Responsive Design (`css/style.css`)

* Mobile-first CSS media queries ensuring fluid layouts across mobile, tablet, and desktop viewports.
* Consistent visual hierarchy utilizing dedicated color palettes, clear typography, and custom form styling.
