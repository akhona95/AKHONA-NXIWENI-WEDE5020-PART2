# Changelog

All notable changes to the **Akhona Help Care** web application project (WEDE5020 Part 2) will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.1.0] - 2026-09-15

### Added
* Created `booking.html` featuring an online appointment booking form with fields for patient details, preferred dates, times, and medical department selection.
* Created `enquiry.html` with a structured client contact form for general medical inquiries and feedback.
* Implemented native HTML5 form validation (required input attributes, pattern matching for phone numbers, and email formatting).
* Added responsive media queries to `css/style.css` for optimal viewing on mobile, tablet, and desktop viewports.

### Changed
* Updated `index.html` header navigation to include active links for `booking.html` and `enquiry.html`.
* Optimized visual hierarchy and CSS flexbox styling across all page layouts for improved readability.

### Fixed
* Corrected image path references for `images/Appointment Online.png` across secondary pages.
* Resolved layout alignment issues on mobile screen width breakpoints.

---

## [1.0.0] - 2026-08-20

### Added
* Initial project scaffold and directory layout for WEDE5020 Part 2.
* Core stylesheet (`css/style.css`) defining primary color palette, base typography, and universal reset styles.
* Base landing page (`index.html`) featuring hero section, service overview, and clinic contact information.
* Added graphic image assets, including clinic logo and appointment banners under `images/`.
* Initial technical documentation (`README.md`).
